# Контракт выгрузки каталога (для интеграции с 1С)

Сайт читает ассортимент из одного JSON. Сейчас это макет —
`catalog.json` со `"source": "mock"`, собранный скриптом
`tools/gen-catalog.js`. Пока стоит `mock`, на каталоге и в карточке
товара висит плашка «черновые данные»; как только придёт настоящая
выгрузка, поле меняется на `"erp"` и плашка пропадает сама.

## Что нужно поменять при подключении

Одна строка в `assets/js/catalog.js`:

```js
var CATALOG_ENDPOINT = 'data/catalog.json';   // ← сюда URL выгрузки 1С
```

Если 1С отдаёт другие имена полей или XML/CommerceML — переписывается
только функция `fromErp()` в том же файле. Остальной код работает
с внутренней моделью и про 1С ничего не знает.

**Важно про CORS.** Браузер ходит за выгрузкой напрямую. Если она
лежит на другом домене, этот домен должен отдавать заголовок
`Access-Control-Allow-Origin`. Иначе выгрузку нужно класть рядом
с сайтом (по расписанию) или проксировать через хостинг.

## Формат

```jsonc
{
  "source":   "erp",                        // "mock" включает плашку «черновые данные»
  "updated":  "2026-08-19T09:00:00+03:00",  // когда выгрузка сформирована
  "currency": "USD",                        // цены хранятся в долларах

  "types": [                                // разделы каталога
    {
      "id":          "futer3",              // латиницей, без пробелов
      "name":        "Футер 3-х нитка",
      "roll_kg_avg": 25,                    // средний вес рулона по типу, кг
      "order":       1                      // порядок в списке разделов
    }
  ],

  "products": [                             // одна запись = полотно в одном цвете
    {
      "id":            "FT3-340P-133",      // уникальный, попадает в ссылку product.html?id=
      "sku":           "00-000123",         // код номенклатуры 1С
      "type":          "futer3",            // ссылка на types[].id
      "name":          "Футер 3-х нитка петля",
      "kicker":        "30/70/10 · 340 г/м²",
      "composition":   "89% хб / 11% пэ",
      "quality":       "компакт пенье",
      "width":         "185–190",           // строка: бывает «100*2», «60,2»
      "density":       340,                 // ЧИСЛО — по нему идёт сортировка
      "density_label": "340",               // строка для показа: «230–240», «250/300»
      "m_per_kg":      1.6,                 // метров в одном килограмме
      "companion":     "Кашкорсе 30/1 220 г/м²",
      "color": {
        "code":    "17-1318 TPG",           // Pantone
        "name":    "Амфора",
        "hex":     "#9F8672",               // приблизительный экранный цвет
        "pantone": "133"                    // номер в палитре компании
      },
      "price_usd_kg":  6.10,                // ЦЕНА ЗА КИЛОГРАММ В ДОЛЛАРАХ
      "roll_kg_avg":   25,                  // необязательно: перекрывает значение типа
      "stock_kg":      340,                 // 0 — позиция «под заказ»
      "photo":         "img/fabric/FT3-340P-133.jpg"
    }
  ]
}
```

Позиции без `id` или с `price_usd_kg` = 0 отбрасываются при загрузке.

## Как считаются рубли

В долларах хранится только цена за килограмм. Всё остальное сайт
считает сам, по курсу ЦБ РФ + 5% из шапки:

| Показатель               | Формула                          |
|--------------------------|----------------------------------|
| Цена за кг, ₽            | `price_usd_kg × курс`            |
| Цена за метр, ₽          | цена за кг **÷** `m_per_kg`      |
| Метров в рулоне          | `roll_kg_avg × m_per_kg`         |
| Стоимость рулона, ₽      | цена за кг × `roll_kg_avg`       |
| Итого в калькуляторе, ₽  | цена за кг × выбранная масса     |

Формулы живут в одном месте — функция `calc()` в `assets/js/core.js`.
Курс берётся с `cbr-xml-daily.ru`, кэшируется в браузере и обновляется
раз в 30 минут; наценка задана константой `FX.MARKUP` там же.

## Корзина

Корзина хранится в браузере (`localStorage`, ключ `saltex-cart`) и держит
только `{id, kg}` — артикул и вес. Ни названий, ни цен: всё остальное
подтягивается из этой же выгрузки, а рубли пересчитываются по текущему
курсу. Поэтому позиция, пролежавшая в корзине неделю, показывает
сегодняшнюю цену, а исчезнувшая из выгрузки — отдельным предупреждением.

Оплаты на сайте нет: кнопка «Отправить заявку» собирает список позиций
и передаёт его в ту же форму, что и запрос прайса.

## Фотографии

Пути — относительно корня сайта, файлы лежат в `img/fabric/`.

- `photo` — обложка: ею показывается позиция в сетке каталога и в корзине;
- `photos` — кадры самой ткани для карточки товара. Первый — главный,
  остальные идут миниатюрами. Обложка сюда не входит.

Если кадр у позиции один, он указывается в обоих полях. Если `photos`
нет, карточка товара берёт `photo`. Если пусто и то и другое, рисуется
нейтральная фактура. Выключатель — `var PHOTOS` в `assets/js/catalog.js`.

После правки `catalog.json` нужно пересобрать `data/catalog.js`: это его
копия для открытия сайта без сервера.

## Пересобрать макет

```
node tools/gen-catalog.js data/catalog.json
```

Скрипт нужен только для черновых данных — после подключения 1С
его можно удалить вместе с этим абзацем.
